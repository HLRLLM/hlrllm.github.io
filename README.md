# Hear, Localize, and Reason

Project page for **"Hear, Localize, and Reason: Spatially Aware Scene Understanding for Audio-visual LLMs"**.

Live site: https://hlrllm.github.io

## Structure

```
index.html              # the page
static/css, static/js   # Nerfies / Bulma template assets
static/images/          # figures exported from the paper
.nojekyll               # serve files as-is (no Jekyll processing)
```

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
